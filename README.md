# 🎂 Chiếc Bánh Sinh Nhật Siêu To Khổng Lồ - Chúc Mừng Sinh Nhật Trần Văn Toàn 🎂

> **Dành tặng:** **Trần Văn Toàn**  
> **Ngày sinh:** **17/11/2003**  
> **Ngày tổ chức:** **17/11/2026** (Cột mốc tròn **23 tuổi**!)  

---

## 🌟 Tính Năng Độc Đáo & Hiệu Ứng Đẹp Mắt
1. **Chiếc bánh sinh nhật 4 tầng siêu to khổng lồ**:
   - Thiết kế 3D isometric hoành tráng, kem chảy, ngọc trai edible, dâu tây lơ lửng.
   - Nến số **23** rực sáng cùng dàn nến sinh nhật với ngọn lửa lung linh.
   - Pháo bông que hai bên phát tia sáng lung linh.
2. **Hiệu ứng Thổi nến ước nguyện**:
   - Dập tắt nến và sinh khói bốc lên mờ ảo chân thực.
   - Kích hoạt tiếng reo hò chúc mừng + mưa pháo hoa (confetti & fireworks) bung nở rực rỡ khắp màn hình.
3. **Nhạc nền Happy Birthday (Web Audio API Synthesizer)**:
   - Giai điệu "Happy Birthday to You" vang lên với âm sắc synthesizer ấm áp, không lo lỗi link âm thanh ngoại tuyến.
4. **Cắt bánh sinh nhật tương tác**:
   - Cắt rời miếng bánh may mắn và hé lộ thông điệp bí mật dành cho tuổi 23.
5. **Bóng bay tương tác**:
   - Các quả bóng bay rực rỡ sắc màu bay lơ lửng, click vào để làm nổ bóng kèm hiệu ứng âm thanh và pháo giấy!
6. **Đổi vị bánh kem tức thì**:
   - 4 hương vị: *Dâu Tây Hoàng Gia*, *Socola Bỉ*, *Matcha Nhật Bản*, *Vũ Trụ Galaxy*.
7. **Bảng tin lời chúc thời gian thực**:
   - Khách mời có thể gửi lời chúc trực tiếp đến Toàn, hiển thị ngay lập tức lên bảng tin.
8. **Hộp quà VIP**:
   - Mở chứng nhận tuổi 23 rực rỡ với những lời chúc ý nghĩa nhất.

---

## 🚀 Cách Chạy Dự Án

### Cách 1: Chạy bằng Python (Khuyên dùng)
```bash
python app.py
```
> Trình duyệt sẽ tự động mở trang web sinh nhật tại địa chỉ `http://127.0.0.1:5000`.

### Cách 2: Chạy nhanh trên Windows
- Nhấp đúp chuột vào file `run.bat`

### Cách 3: Mở trực tiếp (Không cần Python)
- Nhấp đúp chuột vào file `index.html` để mở ngay trên trình duyệt Chrome / Edge!
